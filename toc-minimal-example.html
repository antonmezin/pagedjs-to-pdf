CSS target-counter() Funktion

Die target-counter() Funktion ist das Herzstück der automatischen Seitenzahlen- Generierung. Sie nimmt eine Referenz auf ein Element (über attr(href)) und gibt die Seitenzahl zurück, auf der sich dieses Element befindet.

  content: target-counter(attr(href), page);
  color: #7f8c8d;
  font-weight: bold;
}
